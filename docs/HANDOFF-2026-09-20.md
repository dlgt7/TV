## 4. 功能实现说明（后续 AI 必读）

### 4.1 播放引擎切换

- 问题：设置只写 `player_config_engine`，播放读 `player_engine_vod/live`。
- 修复：`PlayerSetting.putEngine` 同步写全部 key；`getEngine(key)` 的 fallback 也改为 `player_config_engine`。
- 文件：`app/src/main/java/com/fongmi/android/tv/setting/PlayerSetting.java`

### 4.2 EXO 软解

- 问题：EXO「软解」仍用 `c2.qti.avc.decoder`；项目内 Media3 FFmpeg 扩展**仅音频解码器**。
- 修复：soft → `MediaCodecSelector.PREFER_SOFTWARE`（系统 `c2.android.*`）。
- 实测：hard=`c2.qti.avc.decoder`，soft=`c2.android.avc.decoder`。
- 文件：`.../player/exo/ExoUtil.java`、`ExoPlayerEngine.java`

### 4.3 MPV 解码模式

| UI 文案 | decode | hwdec | vo |
|---------|--------|-------|-----|
| 软解 | 0 | no | gpu |
| 兼容硬解 | 1 | mediacodec-copy | gpu |
| 性能硬解/零拷贝 | 2 | mediacodec | mediacodec_embed |

- 直播默认 decode=2（零拷贝）；VOD 默认 decode=1。
- Redmi Note 8 实测三模式均可播；CPU：零拷贝 < 硬解 copy < 软解。

### 4.4 暂停双图层（方案 A′）

- 原因：自定义 `view_control_*` + 内嵌 `PlayerSeekView`（Media3 `PlayerControlView`）双份 chrome。
- 修复：
  - `PlayerSeekView` 隐藏 play/pause、底栏、`exo_controls_background` 等，仅保留进度条。
  - `PlaybackActivity`：`setUseController(false)`、`setControllerAutoShow(false)`。
  - 暂停统一：`onPaused()` + `showControl()`；直播/点播双击对齐。
- 文件：`media3compat/.../PlayerSeekView.java`、`PlaybackActivity.java`、`LiveActivity.java`、`VideoActivity.java`（mobile + leanback）

### 4.5 字幕 ASSRT / 字体

- 设置：播放设置 →「字幕搜索 Token」「字幕字体」。
- 播放：点播/直播字幕轨 → 搜索（Assrt）；本地文件导入保留。
- 配置 JSON 可用 `"assrt": "token"`。
- Token 界面在 `SubtitleApiDialog`；设置项在 `SettingPlayerFragment` / `SettingPlayerActivity`。
- 外置字体：`ExternalFont` → `Path.font()`；`fonts.conf` 含该目录；MPV `sub-font`。
- 字幕面板**长按重置**可选字体（`SubtitleDialog` + `ExternalFontDialog`）。

### 4.6 点播预加载

- 开关：设置 → 预载 →「预载」（`PreloadSetting.isPreload()`）。
- 播放成功后预取下一集 URL；切集/结束自动下一集时优先用缓存。
- 关闭条件：无痕、`useParse`、DRM、空 URL、解析错误等。
- 关键类：`VodPreloadCache`、`VodPlaybackController`、`SiteViewModel.preloadContent`、`VideoActivity.requestPreload`。

### 4.7 音量增益

- 设置 → 播放设置 → **长按「倍速」**：切换 1.0x / 1.5x。
- 持久化 `volume_gain`；`PlayerManager.setPlayer` / overlay sync 时恢复。
- Exo/MPV 均支持 `setVolume`。

### 4.8 弹幕/字幕叠层

- `PlaybackOverlayBinder.sync(PlayerView, PlayerManager)`：统一重绑弹幕 source/config/enabled + 字幕 position/size。
- 在 `configurePlayerView`、`attachSurface`、引擎 rebuild 后调用。

### 4.9 mpv.conf

- 空文件时 `MpvConfigFiles.read()` 返回示例注释。
- 对话框 helper 文案：用户选项优先；vo/hwdec/proxy 仍由应用强制。
