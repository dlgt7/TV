# 推荐页筛选对照（2026-10-07）

参考现有配置中“豆瓣”源 `csp_NewDouBanGuard` 的公开扩展：
https://cdn.waimaimingtang.com/file/images/bwc/20260414181247-ae51abfbfe.txt

只参考其中公开的筛选词表，不加载该源的 JAR，不加入用户配置或凭据。

| 项目 | 实现 |
| --- | --- |
| 片库 | 豆瓣、TMDB 可切换；原 TMDB discover 查询及 genres 接口保留 |
| 豆瓣类别 | 电影、电视剧、综艺；电视剧形式与综艺形式分别展示 |
| 类型与地区 | 使用原源中文标签，不映射为近似 TMDB genre ID |
| 年代 | 原源近 8 个单年、2010 等年代、1960 以前；随当前年份更新 |
| 排序 | 近期热度 T、首映/首播时间 R、高分优先 S |
| 平台 | 电视剧/综艺显示腾讯视频、爱奇艺、优酷、湖南卫视、Netflix、HBO、BBC、NHK、CBS、NBC、tvN |
| 数据 | 豆瓣 `/j/new_search_subjects`，已有豆瓣详情与 TMDB 匹配/全源搜索路径复用 |

原源的“国外”标签在上述官方接口实测返回空，未加入选择项；其余地区包含原源的华语、欧美及具体国家/地区。没有添加原源不存在的评分门槛、评价数要求或排序。

豆瓣会忽略 `year_range=0,1959`，已实测改用 `1,1959`，返回《女驸马》《林家铺子》等 1959 年影片。

请求使用原始标签、`year_range` 和 `sort` 组合，每页 20 条，用原始结果数量决定是否有下一页，避免跳过无海报条目后提前结束分页。切片库清空不兼容筛选，所有请求继续受现有代际检查和去重保护，旧片库迟到响应不会混入新结果。胶囊控件和遥控焦点路径保持不变。

验证：

- 主机实际 HTTP：电影+科幻+美国+2010–2019、电视剧+Netflix、综艺+真人秀+华语、1960 年以前，各返回 HTTP 200 和 20 条结果。
- 电影组合第 2 页返回 20 条，与第 1 页没有重复 ID。
- 9 项本地 JUnit 通过：真实 OkHttp URL 构造、类别/平台/年份/排序组合、清空限制、查询身份、分页、隐藏平台、切片库代际/去重。宿主测试只对 Android 注解、TMDB 常量、Vod ID 容器做轻量 stub；实际业务 query、panel、request state 为生产源码。
- Android CI `37596089839` 与最终测试 CI `37601798522` 全部通过，包括 Discover 查询、解析、请求代际及现有回归测试。
- 三星设备实际首页导航测试通过：首行海报向上进入导航，导航向下返回海报，下方行向上不跳过上一行。该修复先独立发布于 `build-37592149393`。
- 豆瓣实际页面测试通过：电影、Netflix 电视剧、切回电影隐藏平台、华语真人秀四组均返回 20 条，实际筛选 Presenter 的显示/隐藏与请求代际检查通过。报告明确标记 `scope=douban-only`，不将此结果当成 TMDB 联网通过。
- 双库实机测试在 TMDB 阶段未通过：设备请求默认反代发生 `SocketException`，直连官方 API 超时。相同 APK 配置在主机访问默认反代返回 HTTP 200 / 20 条。已修复 validation 构建未注入 TMDB 配置的问题，但设备网络异常仍存在；用户网络设置未修改。
- 最终应用 `77967cc`（`build-37596003921`）已安装，启动正常；11 个配置/数据库文件在覆盖安装前后逐一一致。后续提交只增加测试诊断与明确的豆瓣单库测试模式，默认双库测试仍严格要求 TMDB 返回结果。
