# 播放圆形按钮居中修复

播放/暂停、上集、下集、循环改为直接使用 AndroidX TV Material `IconButton` 与 `Icon`。此前普通文字按钮的内容行最小高度为 40dp，放入 44dp 圆形表面后，24dp 图标整体偏上 2dp。官方图标按钮会在整个表面内居中内容；按钮保持 44dp，保留官方形状与焦点配色，并映射应用调色板。
