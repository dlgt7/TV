## 最终改动

- 首次筛选请求从 6 次降到 1 次。读取实时分类名称与日番筛选，其他已知类别使用与网站逐字段核对的完整定义；打开相应分类后更新内存中的实时筛选，未知分类逐一获取。未访问的已有类别若网站刚新增筛选选项，要访问该类并再次进入源后才体现；重新初始化清空观察缓存。
- 首页/分类成功页面缓存 60 秒、最多 12 页。默认第一页与初始化页面共用缓存，其他页、筛选组合各自隔离；详情与播放地址不进入此缓存。
- 空正文、验证码、登录、错误或残缺页面不缓存。真实网站曾返回 HTTP200 空正文和 PHP 模板错误；未交付早期并发方案，最终没有并发抓取分类筛选。
- 13 组临时主机回归通过，包含完整筛选一致性、未知分类、筛选更新、缓存隔离/失效、失败传播、旧 SDK ABI、完整分类与搜索分页。新版三星验证包含分类/分页/筛选、JOJO 7 条、空搜索、详情和两集地址解析；本次没有重做媒体解码。
