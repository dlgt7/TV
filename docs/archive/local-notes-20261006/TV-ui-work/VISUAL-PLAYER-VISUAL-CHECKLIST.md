## 1. 详情 detail.png

直接观察：

- 小窗外框约x88–968、y92–586；上/下长直白线在圆角处中断，黑色圆角遮罩与白框不是同一连续轮廓。顶部两个角尤其显著；必须解决用户1660明确指出的问题。
- 右侧全屏按钮y496–584几乎只对齐小窗底，次级按钮y600–672悬到小窗以下约86px，整块右侧动作与播放器高度未对齐。
- 播放器左边约88px，选集标题96px，首集chip144px，三个层级没有共同左keyline。集数范围也是标题96px/chip144px。
- 第2集选中与收藏选中均以中灰面表示；当前截图没有可靠证据证明哪个是真实遥控焦点，不应将selected误判focused。
- 标题/metadata当前单行可读，但站源末尾截断；本图不能验证长标题两行或缺metadata时布局。

R2B候选必须检查：

- [ ] 同一影片、同一小窗比例：四角轮廓连续，描边与画面/黑边裁切同形，无直白线露头、角落亮楔、双线。
- [ ] 播放器与整个右栏的顶/底几何对齐；243dp约486px高度约束下两排按钮完整，底排不挤出/遮住选集。
- [ ] title两行、remark、metadata一行、两行people均存在时按钮仍完整；缺remark/metadata/people不留下伪标签和畸形空间。
- [ ] 小窗、选集标题、首chip、集数范围共用48dp内容keyline；focus边缘余量单独计，不再默认多缩进24dp。
- [ ] 普通/选中/焦点区分明确；真实焦点仅一处；中性细边完整、不缩放造成邻项重叠。

功能证据另记：小窗→全屏动作→简介/收藏/换源→选集→上返详情/小窗；OK单次触发、长按不重复收藏、选集长按保持原功能；全屏Back后恢复焦点与播放进度；异步数据不抢别处焦点。

## 2. 控制层 player-controls.png

直接观察：

- 聚焦暂停是明亮白圆，与底部其他深灰按钮反差过强；这不是框架功能错误，但与本轮克制统一焦点方向不一致。
- 标题左沿、暂停圆左沿、上一集圆左沿大致在96px，共用安全线基本成立；候选不能因替换Button改变左线。
- 暂停/进度时间/细时间轴在同一横向区域；暂停圆约92px高，底部图标约88px高，候选应稳定而非按focus增大。
- 底部右侧“播放列表/字幕·音轨/设置”在该图完整可读；普通态不能只为了统一而丢标签或压窄icon。
- 背景为竖向内容并保留两侧黑边，不能把正常源视频比例当UI裁切bug；本图无法验证亮背景下控件对比和横屏视频。

R2B候选必须检查：

- [ ] 同标题/同帧附近/同pause焦点对照，深灰焦点细边仍清晰且无白色大块；按钮宽高在普通/选中/焦点一致。
- [ ] 暂停icon居中，上一集/下一集/重复同尺寸同圆心线；分组button图标/文字与圆按钮中心线协调。
- [ ] 顶部标题长中文省略合理，副标题不覆盖时间轴；底部safe area充足，不贴屏边。
- [ ] 时间轴focus前后不推挤文字或按钮，开始/结束/长时长、seek提示均有空间。
- [ ] 分组active/selected仅变化自身样式，不能产生跨行大面板或撑大按钮。
- [ ] 亮/暗背景、横/竖视频、暂停/播放、直播无duration分别检查可读性与控制层占屏高度。

功能证据另记：所有传输按钮遥控可达；seek左右、OK确认、Back取消；控制层自动隐藏/显示后焦点恢复；previous/next/repeat及各分组回调未变；播放不中断。

## 3. 抽屉 player-drawer.png

直接观察：

- 首项“1.00”为约592×96px亮白块，视觉重量过大。
- 条目只写“1.00/原始/EXO/硬解/片头/片尾”，缺功能名称上下文；新用户无法仅从值直接知道前两项含义。候选应检查可读的label/value或明确命令标题。
- 底部“设置”分组背景异常膨胀：从x880延展到1824约944px，而上一张普通态只约152px宽；文字却在x1320附近，底下另有白点。该状态同时让“播放列表/字幕·音轨”左移。属于明确的选中态几何错误，必须用开/关抽屉同焦点前后图验证已消除。
- 抽屉从y96到984，底部按钮透在后方，最下方内容层级混杂；时间轴终点02:00也隐约透在抽屉下。需评估遮罩透明度、背景控制层处理以及边界。
- 该图只展示6项，不能证明长列表最后项目可达；旧父容器模拟索引也不能作为真实焦点证据。

R2B候选必须检查：

- [ ] 开/关抽屉时底部各按钮位置/宽度不变，设置active不能拉成横条，selected标记不能参与布局撑大。
- [ ] 抽屉标题/条目沿同一内部keyline；边框与列表viewport至少4dp余量，首尾focus边不裁切。
- [ ] 首项焦点深灰且可辨，选中与焦点独立；背景控制层没有第二个像焦点的大白面。
- [ ] 条目明确显示功能标题和当前值；长标题/长值可容纳两行，不只剩“原始”等无上下文值。
- [ ] 多于一屏的条目真实滚动，最后一项完整显示，抽屉不溢出屏幕上下边。
- [ ] 遮罩层保证亮背景下可读，背景时间/按钮透出不能形成误导的可操作层；无双重圆角/边框。
- [ ] 字幕/音轨/播放列表/设置分组各自检查，空组隐藏后不留下不可达焦点。

功能证据另记：进入指定/选中项，真实上下D-pad到首尾，OK及长按单次触发；Left/Back关抽屉回播放按钮；再次Back逐层退出；运行中设置值更新不抢焦点、不重建PlayerView。
